# Procedencia de fuentes

Los archivos de `reference/original` proceden del respaldo aportado por Isaac Lisi del módulo clockwidget 3.8.2. Son referencias históricas y no se incluyen en el APK. La migración conserva expresamente sus fórmulas y geometrías de BLACK_HOLE.

`ClockDrawDocument` conserva el encoder heredado de operaciones del protocolo Remote Compose de plataforma. Las fuentes de AOSP usadas para contrastar el formato y el funcionamiento del reproductor se distribuyen bajo Apache License 2.0 en el repositorio de Android. Los enlaces de cada componente se incluyen en el informe. No se redistribuye el reproductor del sistema dentro de RabbitGlance.

No se asigna una licencia nueva a las fuentes originales del usuario ni se incorpora código del launcher al módulo de aplicación.
